# GT Canvas Software Developer Kit (SDK)

GT Canvas SDK allows software developers to set up a local Canvas learning management system (LMS) implementation for custom Learning Tools Integration (LTI) plugin integration development and testing.

## Requirements

GT Canvas SDK requires the following:

* Docker
* A NodeJS environment
